# CST-250 Minesweeper - Milestone 1

| Project | Purpose |
|---|---|
| MinesweeperClassLibrary | Models (CellModel, BoardModel, GameState) and Services/BusinessLogicLayer (IBoardService, BoardService, DifficultyBase + Easy/Medium/Hard) |
| MinesweeperClassLibrary.Tests | xUnit tests for the business logic layer |
| MinesweeperConsoleApp | Prints color-coded answer keys for a size 10 and a size 15 board |

Open `Minesweeper.sln` in Visual Studio 2022, set MinesweeperConsoleApp as the startup project, and press F5. Run the tests from Test Explorer.
